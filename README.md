# Java_programming
# Introduction
 
This is a respository that Java exercises that aim at strengthening Java concepts such as Object-Oriented Programming

They are designed for learning, practice and academic purposes.

# Objectives
1. To understand Java core syntax and logic
2. Apply Object-Oriented Programming (OOP)
3. Practice problem solving using Java
4. Build small console-based functions

# Technology
a. VS code 
b. git
c. Github

# File Structure
Files are arranged in three main folders namely:
    a. Programs
    b. Instructions Folder
    c. Theory 

The Theory folder holds the theory files containing information that explains the core programming concepts with a few inline illustrations

The Programs folder holds the console-based programs with the subsequent program files. The program written in java code will be found in the 'src' subfolder of each program folder.

The Instructions Folder just contains text files that outline basic instructions to follow when writing a java program.
